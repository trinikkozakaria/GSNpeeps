## Tujuan

Produce a reproducible monorepo in which:

- Nginx serves/proxies the application.
- React builds static production assets.
- Go API and worker share code but run independently.
- PostgreSQL 16, Redis 7, and Nextcloud are internal services.
- OpenAPI is the contract between backend and frontend.
- Configuration, logging, errors, health, shutdown, tests, and migrations have stable
  foundations.

## In scope

- Root repository structure and ignore/editor baseline.
- Docker Compose and internal networking.
- Environment examples without real secrets.
- Backend module, API/worker composition roots, configuration, logging, response, database,
  Redis, router, middleware skeleton, migration runner, and health.
- Frontend React/Tailwind skeleton, design tokens, app shell, routing/provider boundary,
  feedback primitives, API/config boundary, test setup, and mock boundary.
- Complete OpenAPI 3.1 for the approved 42 operations.
- Reproducible commands for dev/build/format/lint/test/E2E/migration/worker.
- Basic CI-ready quality gates.

## Out of scope

- Business CRUD implementation beyond a health endpoint.
- Real employee, attendance, approval, and notification records.
- Production credentials, production deployment, DNS, or live TLS issuance.
- Unapproved frontend/backend libraries.
- Refresh-token endpoint or `/auth/me` not present in the approved contract.
- Hiring Progress, Recruitment Cost, and Benefit beyond later placeholders.

## Verification

Run repository-defined equivalents:

### Contract

- OpenAPI parse/lint with zero errors.
- Operation count and path/method comparison against API Contract v1.1.

### Backend

- Format, vet, lint, unit, integration, and build.
- API/worker start and graceful shutdown.
- Health success and dependency-failure behavior.
- Migration create/up/down-one/re-up on disposable database.

### Frontend

- Format, lint, unit/component tests, static production build.
- Direct-route Nginx fallback.
- Keyboard/landmark/skip-link/mobile smoke checks.
- Production bundle does not contain mocks/secrets.

### Infrastructure

- Compose config validation.
- All internal services reachable only as intended.
- Nginx is the only public ingress.
- Browser network/config inspection exposes no Nextcloud/database/Redis credentials.

Record exact commands and results; do not invent tool names before selection.

## Acceptance criteria

- [ ] Approved architecture/tooling choices are recorded.
- [ ] All service skeletons build reproducibly.
- [ ] API and worker run as separate processes.
- [ ] Docker topology matches System Design and only Nginx is public.
- [ ] `GET /health` behaves according to the approved contract.
- [ ] OpenAPI covers all 42 operations and validates without errors.
- [ ] Frontend produces static assets and renders accessible GSNpeeps shell/feedback states.
- [ ] Configuration fails clearly when required values are absent.
- [ ] No real secret, PII, production URL, or mock data enters production output.
- [ ] Required quality gates pass and are evidenced.

## Exit gate

Do not start Authentication/RBAC until:

- OpenAPI authentication and error contract is stable.
- Role identifiers are confirmed.
- PostgreSQL/Redis migration and connection foundation works.
- Token-storage/frontend bootstrap decision is documented without inventing refresh.
- Backend and frontend skeleton checks pass.
